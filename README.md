# Java 高级工程师 → 架构师学习体系

面向已经能独立完成 Java 业务开发的学习者。用完整知识体系补齐原理，用 **CRM + 交易系统** 检验工程能力；按掌握程度推进，不设固定周计划。

## 交互式 HTML

打开 [Java 进阶图谱](learning-site/dist/index.html)，即可离线阅读全部资料。支持知识模块筛选、全文搜索、单元展开、自评、手记、收藏、阶段检查项、12 道情景小测，以及库存竞态和可靠消息的分步演示。进度仅保存在当前浏览器，可导出/导入备份。

HTML 是单文件，无需安装依赖或联网加载字体、脚本。修改学习文档后，在项目根目录运行 `python3 learning-site/build.py` 重新生成；本地静态检查使用 `python3 learning-site/check.py`。原始 Markdown 仍是学习内容的维护来源。

## 从这里开始

1. 阅读 [学习总纲](ROADMAP.md)，了解能力目标、模块依赖与阶段路线。
2. 执行 [阶段 0：能力诊断](practice/stage-00-diagnosis.md)，先留下自己的答案和实验结果。
3. 在 [个人进度](PROGRESS.md) 登记证据，确定一个主模块和至多一个基础补充。
4. 按 [阶段 1：业务闭环](practice/stage-01-business.md) 开始实践；每个问题回到对应模块学习。

第一次学习可以只做诊断任务 D0-1：实现一个不可变的报价金额模型，解释舍入和状态变化。暂时不会的部分如实记录，不必先读完整套资料。

## 当前交付状态

第一版包含完整总纲、12 份模块指南、6 份阶段手册及记录模板。阶段 0 和阶段 1 已细化为可执行任务；阶段 2–5 提供实践规格与通过标准。模块指南是学习任务与阅读路线，后续教材正文随学习逐节展开。

本仓库目前交付学习文档与离线交互 HTML；尚未创建业务服务或真实组件实验结果。页面中的演示是教学模型，个人能力默认“待诊断”，资料齐备不代表学习已完成。

练习以 Java 21、MySQL 8.4 为基线。Spring Boot 与配套依赖在实践工程建立时锁定稳定版本，核对方式见 [技术基线](resources/REFERENCES.md#baseline)。使用虚构客户数据和模拟支付。
