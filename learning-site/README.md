# Java 进阶图谱 · 离线 HTML

入口是 `dist/index.html`，双击即可在浏览器打开。页面内嵌样式、脚本与全部 27 份学习文档，没有 CDN、远程字体、数据请求或在线账号依赖；外部参考资料链接需要联网访问。

## 提供的阅读与学习交互

- 12 个模块、71 个单元：领域筛选、折叠查看前置/方法/验收、六档自评。
- 6 个实践阶段：可点击路线、完整阶段手册和本地检查项。
- 27 份完整资料：全文搜索、目录跳转、专注阅读、收藏、手记及打印。
- 48 道原有开放题：先独立思考，再展开判断依据。
- 12 道补充情景选择题：即时反馈、解释、重做与模块回看；不自动计入掌握程度。
- 两组手动机制演示：库存竞态/原子更新；Outbox 故障窗口/消费去重。均明确为固定时序的教学模型。
- 浏览器本地记录，可导出/导入 JSON。导入和清空会提示确认。
- 适配桌面与窄屏，支持键盘、搜索快捷键 `/`、Escape 关闭、减少动画和打印。

## 维护与生成

在项目根目录运行：

```sh
python3 learning-site/build.py
python3 learning-site/check.py
```

内容维护在原有 Markdown 文件中；`src/index.html`、`src/styles.css`、`src/app.js` 维护页面与交互。`build.py` 使用 Python 标准库，把目录中约定的 27 份资料编译成单文件 HTML；`dist/index.html` 是应交付和保留的构建产物。

渲染器支持现有文档使用的标题、段落、有序/无序列表、检查项、表格、链接、代码与显式锚点。原始 HTML 默认转义；仅受约束的显式锚点保留。遇到未知本地链接、表格列数错误或未闭合代码块，构建失败，避免静默丢失内容。将来扩展文档或语法时同步修改构建检查。

可选本机预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory learning-site/dist
```

访问 `http://127.0.0.1:8765/`；预览服务器不是离线打开的前提，终端 Ctrl+C 可停止。

## 记录与兼容边界

- 使用 `localStorage`，键为 `java-learning-atlas-v1`。自评以单元 ID 保存，检查项以文档路径和文本摘要保存，避免插入新检查项导致旧状态错位。
- HTML 进度不会反写 `PROGRESS.md`；跨浏览器、不同预览端口和文件地址的记录彼此独立。文件模式的存储行为由浏览器决定，受限时页面提示导出备份。
- 备份验证版本、已知文档/单元/检查项 ID、数值范围及手记长度；导入不执行文件中的脚本或 HTML。
- 建议使用支持原生 dialog、details、CSS Grid 与现代 JavaScript 的当前浏览器；不支持旧版 IE。
- 学习内容与页面本地可用；资料站点的内容、可达性与版本仍以外部官方文档为准。
